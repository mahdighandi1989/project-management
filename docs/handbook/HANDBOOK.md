## ۱. هدف و نقشهٔ کلیِ برنامه
ساخت، پایش، اجرا و نگه‌داریِ پروژه‌های نرم‌افزاری با هوش مصنوعی. بک‌اند FastAPI (`backend/app`) و فرانت Next.js
(`frontend/src`) روی Render؛ هر push به `main` دیپلوی است. صفحه‌ها (از رجیستری): خانه · پروژه‌ها و نمودارها · اتاق فرمان ·
نظارت و سرکشی · موتور خالق · مرکز دانش · آرشیو · جزوه و دفتر کار · مدل‌ها و تنظیمات؛ و بیرون از منو: تحلیل پروژه، پروفایلِ مدل‌ها،
مناظره (بایگانی)، کاربران. نقشهٔ کاملِ مسیرها: جدولِ «ساختار» در [`CLAUDE.md`](../../CLAUDE.md).

## ۲. اتاق فرمان
شناختِ کامل، تاریخچهٔ فاز به فاز، ۱۸ ایرادِ رفع‌شده و ۱۳ ایرادِ باز: **[اتاق فرمان — شناختِ کامل](OVERSIGHT.md)**.
خلاصه: ایده ⇐ پرامپتِ قوی ⇐ تسک ⇐ اجرا (دستی / Claude Runner / بازرس) ⇐ تأییدِ مستقل با AC ⇐ گزارش و تلگرام؛ اسکنِ عمیقِ
دوره‌ای تسک‌های پیشنهادی می‌سازد. ساخته‌شده در ۹ مه تا ۲۸ ژوئن ۲۰۲۶ (۳۸۵ کامیت).
**کارتِ هر پروژه (۲۰۲۶-۱۱-۱۵):** راهنمای کاملِ هر تنظیم، فلسفه و وضعیتِ واقعیِ Claude Runner و TO-DO: [OVERSIGHT.md به‌روزرسانیِ (و)](OVERSIGHT.md). «زمان‌بندی فعال» سوییچِ اصلیِ اسکن، verify و اجراست؛ اسکنِ بی‌مدل شکست است. موارد بازِ آن بازبینی هم بسته شد ([OVERSIGHT.md (ز)](OVERSIGHT.md)).
**اجرای خودکار (۲۰۲۶-۱۱-۱۵، PM-INS-0008):** پروژهٔ «فقط verify» عمداً اجرا نمی‌شود (هر ۹ پروژه از خرداد چنین بودند — علتِ «بعدی» ِ ۵ ماه پیش)؛ کارت حالا
وضعیتِ واقعی را از `autorun_state` می‌گوید (کهربایی «فقط verify»، قرمز «⚠️ عقب‌افتاده»، شمارِ تسک‌های آمادهٔ auto از pending) و دکمهٔ «▶️ اجرای الان»
(`POST /api/oversight/watched/{id}/autorun-now`، در پس‌زمینه، «فقط verify» را رعایت می‌کند) دارد. پروژهٔ بی‌مدل از `_default_watch_models` (default_models، وگرنه
deepseek-chat، وگرنه cloud_code) استفاده می‌کند و کارت «✨ پیش‌فرضِ خودکار» نشان می‌دهد.
**مدل‌ها (۲۰۲۶-۱۱-۱۵):** فعال‌سازیِ موقتِ مدل‌ها دیگر هرگز مدلی را که سابقه‌اش معلوم نیست خاموش نمی‌کند (علتِ «همهٔ مدل‌ها رفتند»).
آخرین وضعیت (۲۰۲۶-۱۱-۱۵): ایرادهای باز و تأییدشدهٔ بازبین‌ها در چهار دسته رفع شد — آخرینش لاگِ هر پروژه فقط از سرویس‌های خودش، بازهٔ زمانیِ
حداقل ۰٫۲۵ ساعت، آپلودِ بی‌رقابت و مدلِ موقتِ خودبازگردان (OVERSIGHT.md به‌روزرسانیِ «د»).
گزارش‌های قدیمی (بیش از ۳۰ روز، نه آخرینِ تسک) وقتی `reports.json` بزرگ شد کامل به درایو می‌روند و نسخهٔ سبکشان می‌ماند؛ باز کردنشان نسخهٔ کامل را
خودکار برمی‌گرداند (`services/reports_archive.py`). `tasks.json`/`reports.json` در پس‌زمینه نوشته می‌شوند و درخواست‌ها را معطل نمی‌کنند.

## ۳. نظارت و سرکشی و ناظرِ خودکار
مالک روی هر صفحه کادر می‌کشد یا درخواستِ عمومی می‌نویسد، فایل پیوست می‌کند (به گوگل درایوِ پروژه منتقل می‌شود؛ دیسکِ Render
فقط ۱GB است)؛ ناظرِ خودکار دو بار در هفته (و صفِ فوری هر ۳ ساعت) برگه‌ها را رسیدگی و پاسخ می‌دهد. راهنما:
[`docs/supervisor/README.md`](../supervisor/README.md)؛ دستورِ نسخه‌دار: `docs/supervisor/PROMPT.md`.

## ۴. پروژه‌ها و بازرس ویژه
`/projects` پروژه‌ها (و تبِ «نمودارها»)؛ `/projects/[id]` تب‌های هر پروژه از جمله «بازرس ویژه» (چت روی کد، اعمالِ تغییر با PR،
ضبطِ آزاد/داخلِ پروژه با لاگ و ویدیو، اسکرینِ زندهٔ فرانت کنارِ چت). وضعیت و برنامهٔ بهبود: بندِ ۱۲ ِ طرحِ مالک ([دفتر کار](../WORKLOG.md)).
- **نمودارها ذیلِ هر پروژه (۲۰۲۶-۱۱-۱۶، PM-INS-0004):** تبِ «📈 نمودارها» در `/projects/[id]` (`?tab=diagrams`؛ `components/ProjectDiagramsPanel.tsx`)
  نمودارهای ذخیره‌شدهٔ همان پروژه و «🪄 رسم خودکار» را دارد؛ تبِ «📊 نمودارها» در `/projects?view=diagrams` سرِ جایش است و رسمِ خودکارش هم ذیلِ پروژه ذخیره
  می‌شود. ذخیره: `GET/POST /api/diagrams/saved` در `DATABASE_DIR/diagrams_saved.json` (همان کد دوباره ذخیره نمی‌شود، سقفِ ۲۰۰ در هر پروژه، بی‌حذفِ خاموش).
  فهرستِ «پروژه» مخزنِ تحت نظارتی را که پروژهٔ محلیِ وصل به همان مخزن دارد دوباره نشان نمی‌دهد.
- **کارتِ مدل و «API ✓» (۲۰۲۶-۱۱-۱۵، PM-INS-0005):** «API ✓» فقط پس از یک فراخوانیِ واقعیِ موفق (`advanced_settings.last_call` که «تست توانایی» می‌نویسد،
  `model_capability_tester.record_last_call`)؛ کلیدِ تنها = «کلید ✓ · آزموده نشده»؛ شکست = «API ✕» + متنِ واقعیِ خطا در کارت به‌جای «۰ مبتدی». روشن‌کردنِ دستیِ مالک
  پرچمِ «موقت» را پاک می‌کند تا پاک‌سازیِ فعال‌سازیِ موقت آن را خاموش نکند؛ toggle ِ مدلِ بی‌ردیف پیش‌فرضِ رجیستری را برمی‌گرداند.
- **عامل و ضبط (۲۰۲۶-۱۱-۱۵، PM-INS-0012):** عاملِ مرورگر روی خودِ AI Creator، بی‌Recipe، با نشستِ **همان کاربر** وارد می‌شود (`browser_agent._own_session_state`:
  توکنِ bearer ِ درخواست ⇒ `localStorage['pm.auth.token']` ِ زمینهٔ یک‌بارمصرف، فقط وقتی صفحهٔ شروع هم‌سایتِ Origin است) و میزبانِ API مجاز می‌شود؛ بی‌Recipe و
  بی‌جلسه پیش از شروع می‌گوید. «🎬 ضبط» پنجره را فوراً باز می‌کند (مجوزِ میکروفون بعد) و پنجره‌ها با portal در `<body>`اند. «لایه خطا» ِ پل فقط برای لایهٔ شبیهِ خطا.
- **پایداریِ چت (۲۰۲۶-۱۱-۱۵، PM-INS-0006):** هر درخواستِ smart-chat از `_FallbackAIManager` می‌گذرد — مدلِ خراب ⇒ خودکار gemini-2.5-flash، deepseek-chat، …
  (OAuth آخر)، با یادداشتِ «⚠️ مدل X خطا داد — با Y ادامه» و نامِ مدلِ واقعی زیرِ پاسخ؛ خطای همهٔ مدل‌ها «خطای مدل» است نه «خطای GitHub». «Local AI» اول مدل‌های API
  را برمی‌گزیند و cloud_code را فقط وقتی هیچ مدلِ API نیست. موتورِ Cloud Code بی‌پاسخ ⇒ همان پیام با Local AI. شناسهٔ Cloud Code از `CLOUD_CODE_CLI_VERSION`
  (پیش‌فرض 2.1.0) و با 400 ِ «does not support this model» خودش ارتقا می‌یابد. «Failed to fetch» = سرور در حالِ دیپلوی/بیدارشدن (نه پاور) ⇒ انتظار برای `/health`.
  نشانِ GitHub همان کلیدهای سینکِ پروژه را می‌خواند (`_github_token_from_db`). پرامپتِ سؤال ۵ کامیتِ آخر را زنده دارد.
- **سؤالِ ساده، جوابِ ساده (۲۰۲۶-۱۱-۱۶، PM-INS-0007):** پیامِ کوتاهِ پرسشیِ بی‌اشاره به مشکل/تغییر («آخرین commit چیست؟») بی‌فراخوانیِ مدل «سؤال» است
  (`services/inspector_quick_classify.py`) و به حالتِ عامل نمی‌رود. عامل و موتورِ Cloud Code ابزارِ `list_commits` دارند (هش، زمان، نویسنده، پیام؛ زنده از GitHub).
  سرِ چت پس از اولین پاسخ نامِ **مدلی که واقعاً جواب داد** را می‌گوید («پاسخِ آخر: …») و پیامِ مسیریابیِ عامل نامِ مدلِ واقعی را، نه «Claude» ِ ثابت.
- **مدلِ چت (۲۰۲۶-۱۱-۱۵، PM-INS-0002):** مدل‌های OAuth (مثلِ `cloud_code`) هم «روشن» شمرده می‌شوند (`render_logs._oauth_model_ready` — همان قاعدهٔ
  `ai_manager.get_available_models`)؛ مدل‌ها همان اولِ تب بار می‌شوند و انتخابِ خودکار بهترین مدلِ روشن (رتبهٔ موفقیت) را برمی‌گزیند و نامش را در سرِ چت
  نشان می‌دهد («✨ خودکار: …»)؛ اگر هیچ مدلی روشن نیست صریح می‌گوید. اسکرین و چت واکنش‌گرا هستند (flex-wrap؛ در عرضِ کم چت زیرِ اسکرین می‌رود).
- **اسکرینِ کنارِ چت:** iframe ِ `/api/render/inspector/proxy/{پروژه}/…` (پروکسیِ خودِ بک‌اند از فرانتِ پروژه). از ۲۰۲۶-۱۰-۰۸ دیوارِ ورود آن را
  (و هر ضبط و عکسی از آن را) 401 کرده بود؛ اکنون با **بلیتِ پیش‌نمایش** — امضاشده، فقط برای همان پروژه، ۳۰ دقیقه، در کوکیِ محدود به مسیرِ همان
  پروکسی (`core/auth.preview_*`، `lib/previewTicket.ts`) — باز می‌شود و صفحهٔ خطا را تشخیص می‌دهد و خودش بلیت را تازه و دوباره بار می‌کند.
- **ضبط:** هر تکه با ۳ بار تلاش و پیش از «پایان» منتظرِ همهٔ تکه‌ها؛ **ری‌استارت/دیپلوی ِ سرور وسطِ ضبط** دیگر ضبط را از بین نمی‌برد — مرورگر جلسه را با همان شناسه بازمی‌سازد و تکه‌های نگه‌داشته را دوباره می‌فرستد (`/resume`)؛ توقفِ خودکار (Stop sharing، ۶۰ دقیقه) واقعاً کار می‌کند؛ در حالتِ «داخلِ پروژه»
  قاب‌ها با ffmpeg از ویدیو درمی‌آیند تا تحلیلِ تصویری انجام شود؛ نتیجهٔ ارسال (خطا/هشدار) نشان داده می‌شود؛ پرامپت در کادرِ چتِ بازرس می‌نشیند.
- **پرامپتِ فشرده (۲۰۲۶-۱۱-۱۵):** مدل‌های کوچک/ارزان دستوراتِ عمومی را در ~۳ هزار نویسه (به‌جای ~۲۵ هزار) و پرامپتِ عاملِ کوتاه می‌گیرند؛ همه نقشهٔ واقعیِ فایل‌های مخزن را می‌بینند (`services/inspector_compact_prompt.py`؛ اجبار: `INSPECTOR_COMPACT_PROMPT`).
- **چت برای مدل‌های ضعیف:** فایل‌های بزرگ دیگر بی‌صدا بریده نمی‌شوند — نقشهٔ کاملِ فایل + سرِ فایل، و خواندنِ بازهٔ شماره‌دار (`start_line`/`end_line`)،
  ابزارهای `search_code` و `file_outline` (`services/inspector_code_tools.py`)؛ پیش از پذیرشِ action_plan هر `find` با فایلِ واقعی سنجیده می‌شود و اگر
  نبود نزدیک‌ترین متنِ واقعی به مدل برمی‌گردد تا خودش اصلاح کند (تا ۲ بار؛ خاموش‌کردن: `INSPECTOR_VERIFY_FIND=0`)؛ JSON ِ پاسخِ مدل‌های ضعیف با ترمیم پذیرفته می‌شود.
- **عاملِ مرورگر (🖱 عامل، کنارِ دکمهٔ ضبط):** کار روی سایت مثلِ کاربر — فرم، کلیک، ناوبری — با Chromium ِ سمتِ سرور، گام‌به‌گام: مدل فقط فهرستِ
  شماره‌دارِ عناصر و خلاصهٔ متنِ صفحه را می‌بیند (مدل‌های تصویری عکس هم) و هر بار **یک** کارِ کوچکِ JSON برمی‌گرداند؛ پاسخِ نامعتبر یک بار با خطای
  دقیق برمی‌گردد؛ تکرارِ بی‌اثر ⇒ «گیر کرد». ایمنی روی سرور: سایت‌های غیرمجاز در لایهٔ شبکه مسدود، ثبت/ارسال/حذف/پرداخت/رمز منتظرِ «اجازه»، رمزها فقط
  با ارجاع به `WATCHED_AUTH_*`، یک اجرا در هر زمان، سقفِ گام و زمان. هر گام (دید، فکر، کار، نتیجه، عکس) ثبت و قابلِ دانلود و ارسال به چت است
  (`services/browser_agent.py`، `/api/inspector-agent/*`، `components/BrowserAgentPanel.tsx`).
- **ایمنی و کیفیتِ تکمیلی (دستهٔ ۳):** ویدیوی ضبط برای تلگرام به MP4 ِ قابلِ پخش تبدیل و در صورتِ بزرگی به **بخش‌های زمانیِ** مستقل تقسیم می‌شود (نه برشِ بایتی)،
  صدا به m4a؛ سمتِ «inspector» ِ سوکتِ پل بلیتِ پیش‌نمایش لازم دارد (فرمانِ کلیک/ناوبری فقط از مالک)؛ حالتِ Cloud Code پلانش را دیگر دور نمی‌ریزد (دکمهٔ اعمال)
  و شاخهٔ واقعیِ مخزن را می‌خواند؛ فایلی که بخش‌هایش فقط تا نیمه جور شد، نیمه‌کاره commit نمی‌شود (`INSPECTOR_ALLOW_PARTIAL_APPLY=1` برای اجازه).
- **اسکرینِ خودترمیم (دستهٔ ۴):** اگر iframe بار نشود یا خالی بماند، خودکار به **«نمای سرور»** می‌رود (عکسِ زندهٔ همان صفحه از Chromium ِ سرور هر ۴ ثانیه،
  `GET /api/inspector-agent/snapshot`) و هر دقیقه دوباره iframe را امتحان می‌کند. عاملِ مرورگر اگر پروژه Auth Recipe داشته باشد اول خودش وارد می‌شود. ضبطِ نهایی (ویدیو،
  صدا، پرامپت) به پوشهٔ «ضبط‌های بازرس» در گوگل درایو هم می‌رود. انتخابِ خودکارِ مدل در چت بر اساسِ **نرخِ موفقیت**، نه تعدادِ استفاده.

## ۵. دستیار، راهنما و خانه
- **دستیار** (`services/assistant.py`): هر پرسش ⇐ نقشهٔ صفحه‌ها + راهنمای صفحهٔ جاری + ۶ ورودیِ آخرِ دفتر کار + ورودی‌های مرتبط + ۱۵ کامیتِ آخر +
  وضعیتِ زنده؛ «چند مدل» تا ۴ مدل؛ گفت‌وگوها در «آرشیو».
  آرشیو (PM-INS-0007): مناظره‌ای که دوبار با همان متن و همان ثانیه ساخته شده یک‌بار نشان داده می‌شود (فایل‌ها حذف نمی‌شوند)؛ مناظره‌ای که بیش از ۲ ساعت در
  فازِ میانی (synthesizing، judging، …) مانده، با نتیجه «کامل‌شده» و بی‌نتیجه «ناموفق» می‌شود (`metadata.stale_reconciled`)؛ برچسب‌های وضعیت فارسی‌اند.
- **دایرهٔ راهنما**: متنِ دستی هر جا هست + راهنمای خودکار از رجیستری برای همهٔ صفحه‌ها + «این صفحه الان» (خواندنِ زندهٔ صفحه) + «تغییراتِ اخیر» (کامیت‌های همان صفحه).
- **خانه**: کارت‌ها از رجیستری، وضعیتِ زنده، «تازه‌ها» از GitHub.

## ۷. ورود، امنیت و زیرساخت
همهٔ API پشتِ «ورود با گوگل» (`core/auth.py`)؛ فراخوانِ ماشینی فقط با `X-External-Token` / `X-Supervisor-Token`. کلید/رمز/ایمیل
فقط در متغیرهای محیطیِ Render. بک‌اند از `./backend` ساخته می‌شود ⇒ `docs/` در کانتینر نیست؛ جزوه، دفتر کار، خانه و دستیار آن را
زنده از GitHub می‌خوانند (`services/repo_docs.py`). فایل‌های حجیم ⇐ گوگل درایو (`services/gdrive.py`).
