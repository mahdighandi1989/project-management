## اجرای ۰ — ۲۰۲۶-۱۰-۰۸ — راه‌اندازیِ سامانه (دستی، نه روتین)

  دقیق (گره + کسرها + مختصاتِ سند + زبانه)، تصویرِ خودکارِ علامت‌خورده یا اسکرین‌شاتِ چسبانده،
  ثبت «گزارشِ جدید» یا «ذیلِ یکی از گزارش‌های باز»، پیوستِ هر نوع فایل (تکه‌ای، قابلِ ادامه)،
  ⚡ فوری با شمارش‌گرِ دورِ بعد، رنگ بر اساسِ وضعیت (نارنجی/سبز/آبی/خاکستری) روی کارت و هایلایت،
  درخواستِ عمومی، نقشهٔ سامانه (همهٔ صفحه‌ها و زیرصفحه‌ها با مختصاتِ عنصرها)، بایگانیِ زونکنی،
  انتقالِ فایل‌ها به گوگل درایو و پاک‌کردنِ نسخهٔ سرور پس از تطبیقِ MD5.
- **راستی‌آزمایی:** `pytest` بک‌اند — ۷۰۲ قبول، ۳ رد (skip)؛ ۱۴ تستِ تازهٔ `tests/test_inspection.py`.
  `npm run build` سبز. سرتاسری با Chromium روی نسخهٔ محلی: کادر → برگه با فایل و ⚡ → هایلایتِ
  نارنجی → ذیلِ برگه با کادرِ خودش → هایلایتِ دوم بلافاصله → `urgent` (خروج ۵) → `answer fixed`
  بدونِ عکس رد شد، بدونِ `--place` رد شد، با هر دو پذیرفته شد (سبز) → تأییدِ مالک (آبی) → `file`
  بایگانی کرد. `surface_scan.py` محلی: ۱۳ صفحه، ۲۵ نقشهٔ صفحه/زبانه، ۰ شکست.
- **ماند:** OPEN_ITEMS ‏#۱ (درایو)، #۲ (توکنِ اختصاصی)، #۳ (نمونهٔ صفحه‌های پویا).
