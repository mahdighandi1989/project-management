# کارتابلِ «نظارت و سرکشی» — پوشهٔ کاریِ ناظر

این پوشه **حافظه نیست**، یک کپیِ کاری است. برگه‌ها در API زندگی می‌کنند (`/api/inspection`) و در
صفحهٔ «نظارت و سرکشی» دیده می‌شوند؛ این‌جا فقط چیزی است که ناظر برای خواندنشان لازم دارد.

```bash
python3 scripts/supervisor/inspection.py file    # تیک‌خورده‌های مالک → زونکن
python3 scripts/supervisor/inspection.py pull    # QUEUE.md + shots/ + files/
python3 scripts/supervisor/inspection.py urgent  # URGENT.md (یک برگهٔ فوری)
```

- `QUEUE.md` / `URGENT.md` — متنِ مالک، نشانیِ دقیقِ بازگشت (با زبانه)، گره و کسرهای داخلِ گره،
  آنچه داخلِ کادر بود، و کادرهای یادداشت‌های ذیلِ برگه.
- `shots/` — تصویرِ هر یادداشت. **بازشان کن و نگاه کن.**
- `files/` — متنِ **کاملِ** فایل‌های پیوست (تکه‌تکه تا آخر) یا خودِ فایل وقتی متن ندارد.
  «حجمش زیاد است» عذر نیست — تا فایلی خوانده‌نشده بماند، API جوابِ برگه را رد می‌کند.

همه با هر اجرا از نو ساخته می‌شوند و در git نیستند (`.gitignore` همین پوشه)؛ فقط این README کامیت می‌شود.
