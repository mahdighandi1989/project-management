# بایگانیِ نسخه‌های دستورِ ناظر

هر بار که `../PROMPT.md` یا `../URGENT_PROMPT.md` عوض می‌شود، نسخهٔ **قبلی** پیش از ویرایش
این‌جا کپی می‌شود — هرگز پاک نمی‌شود:

- `PROMPT-v{N}-{YYYY-MM-DD}.md` — دستورِ دورِ کامل
- `URGENT_PROMPT-v{N}-{YYYY-MM-DD}.md` — دستورِ صفِ فوری

`N` همان `version` ِ frontmatter ِ نسخهٔ بایگانی‌شده است، و فیلدِ `supersedes` در نسخهٔ تازه به
همین فایل اشاره می‌کند. (الگوی ALLIN1 و Detective-1.) نسخهٔ ۱ هر دو دستور در ۲۰۲۶-۱۰-۰۸ ساخته و همان روز با نسخهٔ ۲ جایگزین شد
(افزودنِ دفترِ کار، `scripts/ship.sh` و ورود با گوگل).
