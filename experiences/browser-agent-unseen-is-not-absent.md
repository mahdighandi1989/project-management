# عاملِ مرورگر: «ندیدم» ≠ «نیست»

## 🎯 چالش / Challenge
یک عاملِ LLM که با مرورگرِ سمتِ سرور روی سایت کار می‌کند، جستجویی انجام داد و «۰ نتیجه» را به‌عنوانِ واقعیت گزارش کرد. در مرورگرِ واردشدهٔ
کاربر همان جستجو ده‌ها نتیجه داشت. مرورگرِ عامل وارد نشده بود و دادهٔ برنامه (که در ذخیره‌سازیِ مرورگرِ کاربر/حسابِ او بود) اصلاً بار نشده بود؛
چند درخواستِ داده هم به‌خاطرِ فهرستِ مجازِ میزبان‌ها مسدود شده بود. صفحه صادقانه «نتایج: ۰» نشان می‌داد و مدل همان را خواند.

## 💡 راه‌حل / Solution
۱. **وضعیتِ صفحه را موتور بسنجد، نه مدل** — در هر گام، از همان مشاهده‌ای که به مدل می‌رود: واردشده/نشده (دکمهٔ ورود یا خروج، فیلدِ رمز، نشانیِ
   ورود)، نشانهٔ خالی («۰ نتیجه»، «یافت نشد»)، هنوز در حالِ بارگذاری، و درخواست‌های داده‌ای که خودِ موتور مسدود کرده است.
۲. **همان را به مدل نشان بده** (یک خطِ `PAGE STATE`) و بگو خواندهٔ خالی روی چنین صفحه‌ای واقعیت نیست.
۳. **حکم را در کد بده:** اگر خوانده «خالی/صفر/پیدا نشد» است و صفحه واردنشده/مسدود/درحالِ‌بارگذاری است، وضعیتِ پایان «نامطمئن» است با دلیل —
   حتی اگر مدل «۰» گفته باشد. گفتهٔ مدل را نگه دار ولی با برچسبِ «تأییدنشده».
۴. **هر پایان یک خطِ شواهد:** عنوان/نشانی، وضعیتِ ورود، و متنِ دقیقی که جواب از آن خوانده شد — و آن متن را با خودِ صفحه بسنج (✓/✗).
۵. **پایان را تا آرام‌شدنِ صفحه نگه دار:** اگر صفحه بینِ «خواندنِ مدل» و «پایان» عوض شد، دوباره نشانش بده (با سقفِ تکرار).

## 🧪 نمونه کد (Anonymized)
```python
def doubt_reasons(state, summary):
    reads_empty = bool(state["empty"]) or ZERO_CLAIM_RE.search(summary)
    if not reads_empty:
        return []          # «وارد نشده» به‌تنهایی دلیلِ شک نیست
    reasons = []
    if state["signin"] == "out": reasons.append("not signed in")
    if state["blocked"]:         reasons.append("data requests blocked by the allow-list")
    if state["loading"]:         reasons.append("still loading")
    return reasons          # غیرخالی ⇒ status = "unreliable"
```

## ⚠️ نکات حیاتی / Pitfalls
- قاعده را فقط در پرامپت نگذار؛ مدلِ ضعیف همان «۰» را می‌گوید. حکمِ نهایی باید در کد باشد.
- «وارد نشده» را به‌تنهایی «نامطمئن» نکن — تقریباً هر سایتِ عمومی دکمهٔ ورود دارد و همهٔ نتیجه‌ها بی‌دلیل زرد می‌شوند.
- واژهٔ «ورود» در یک عنوان («ورودِ داده») دکمهٔ ورود نیست؛ فقط کنترل‌های کوتاهِ قابل‌کلیک را بسنج.
- درخواست‌های تله‌متری/فونت که همیشه مسدودند را از «دادهٔ مسدود» کنار بگذار وگرنه همیشه هشدار می‌دهد.
- رقم‌های فارسی/عربی را پیش از تطبیق یکسان کن («٠»، «۰»، «0»).
- کادرِ جستجو را فقط وقتی «امن» بدان که Enter نتواند چیزِ دیگری ثبت کند: بی‌فرم، یا تنها فیلدِ یک فرمِ GET.

## 🔁 چطور در جای دیگر اعمال کنیم / How to Apply Elsewhere
- هر ابزارِ خودکاری که «چیزی پیدا نشد» گزارش می‌کند باید جدا بگوید «توانستم نگاه کنم؟». اگر نه، خروجی «نامعلوم» است نه «صفر».
- برای هر عددی که عامل گزارش می‌کند، منبعِ دقیق (متنِ نقل‌شده + نشانی) را بخواه و ماشینی با منبع بسنج.
- آزمون را روی صفحه‌ای با همان شکلِ واقعی بنویس: یک بار بی‌نشست (باید «نامطمئن» بگوید) و یک بار با نشستِ حاملِ داده (باید عددِ واقعی بگوید).
